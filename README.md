# Techronyx E-Commerce

A React storefront backed by a Django REST API. The application supports product browsing, JWT authentication, and a per-user cart.

## Project structure

- `frontend/ecommerce/` — React application
- `backend/ecomm/` — Django application and Render deployment definition

## Local setup

### Backend

```powershell
cd backend/ecomm
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

The API is available at `http://127.0.0.1:8000/api/`. Initial migrations seed the product catalog.
Copy `backend/ecomm/.env.example` to `backend/ecomm/.env` when you need to override local settings.

### Frontend

In a second terminal:

```powershell
cd frontend/ecommerce
npm ci
npm start
```

The development app runs at `http://localhost:3000` and targets the local API by default. Set `REACT_APP_API_URL` before starting the app to use a different API deployment.

## Deployment

`backend/ecomm/render.yaml` defines the Render web service. Configure `DATABASE_URL` as a secret in Render; `SECRET_KEY` is generated by Render. Migrations run automatically during deployment.

## Verification

```powershell
cd backend/ecomm
.\.venv\Scripts\python.exe manage.py check

cd ../../frontend/ecommerce
npm run build
```
